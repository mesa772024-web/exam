# موقعا مكتب بغداد الحياة العلمي ومكتب الحياة العلمي

| المجلد | الموقع | ما الذي تغيّر عن النسخة الأصلية |
|---|---|---|
| `baghdad-alhayat/` | مكتب بغداد الحياة العلمي | نفس المحتوى والأقسام والمقدمة السينمائية — تغيّر الاسم إلى «بغداد الحياة»، والهوية البصرية إلى العنابي (الألوان، الشعار، الشعار المتحرك، تلوين الفيديوهات والصور) |
| `alhayat/` | مكتب الحياة العلمي | نفس الموقع تماماً — تحسين CSS فقط |

في الموقعين: اللغة الافتراضية **الإنكليزية فقط** (إعداد `siteLanguages = en`)،
ويمكن تغييرها من لوحة الإدارة ← الهوية والإعدادات ← «لغات الموقع».

## الرفع على الاستضافة
كل مجلد حزمة PHP + MySQL كاملة (نفس طريقة التثبيت الأصلية — راجع `INSTALL_AR.md` داخل المجلد):
ارفع محتوى المجلد إلى `public_html` ثم افتح `/install/`.

## أدوات (`tools/`)
| الملف | الوظيفة |
|---|---|
| `rebrand_baghdad.py` | يحوّل نسخة من الموقع الأصلي إلى بغداد الحياة (الاسم + تحويل كل الألوان الخضراء إلى العنابي) |
| `burgundy_lut.py` + `recolor_media.sh` | تحويل اللون الأخضر في الفيديوهات والصور إلى العنابي (الأوراق، الأعلام…) |
| `polish-home.css` / `polish-inner.css` + `apply_polish.py` | تحسينات CSS (للموقعين؛ تُلوَّن بالعنابي لبغداد الحياة) |
| `export_static.py` | يصدّر نسخة HTML ثابتة للمعاينة على GitHub Pages |
