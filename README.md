# موقع مكتب بغداد الحياة العلمي — Baghdad Al Hayat Scientific Office

موقع ثنائي اللغة (عربي / English) بالهوية البصرية لبغداد الحياة: الورقة التي تُرسم بالقلم،
الشعار الذي يُكتب حرفاً حرفاً، لمعة الضوء، الجزيئات الطائرة، واللونان #A00B4C و #960C0E.

## الصفحات
| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية — مقدمة رسم الشعار، الأرقام، القصة، الخدمات، الجودة، الشركاء، شبكة التوزيع |
| `about.html` | من نحن — المهمة والرؤية، القدرات، الهيكل التنظيمي، القيادة، المحطات، الفريق |
| `services.html` | الخدمات الست بالتفصيل |
| `quality.html` | الجودة والامتثال — GSDP وأنظمة ISO وسلسلة التبريد والمرافق واليقظة الدوائية |
| `partners.html` | الشركاء العالميون والتزاماتنا |
| `contact.html` + `contact.php` | نموذج التواصل والعناوين |

## الرفع على الاستضافة
ارفع كل الملفات كما هي إلى `public_html` (مجلد `tools/` غير ضروري على الخادم).
- لا يحتاج الموقع قاعدة بيانات.
- النموذج يرسل عبر `contact.php` (PHP `mail()`). عدّل `MAIL_TO` و `MAIL_FROM` داخله.
  إن لم تتوفر PHP يفتح الموقع برنامج البريد لدى الزائر تلقائياً.

## تعديل المحتوى
كل النصوص (عربي/إنجليزي) موجودة في `tools/build.py`. بعد التعديل:
```bash
python3 tools/build.py
```
يعيد توليد صفحات HTML الست بنفس الترويسة والتذييل.
