# 118 Team Banks

واجهة مبدئية لمنصة امتحانات طبية مبنية بـ PHP و Bootstrap. تضيف الملفات الحالية هيكلية بسيطة لعرض الصفحات الأمامية مع ربط الشعار وروابط التواصل المطلوبة.

## التشغيل المحلي
1. أنشئ قاعدة بيانات MySQL ثم نفذ السكريبت `database/schema.sql` لإنشاء الجداول.
2. حدّث بيانات الاتصال في `config.php`.
3. شغّل خادماً محلياً يشير إلى مجلد `public/` مثل:
   ```bash
   php -S localhost:8000 -t public
   ```
4. افتح المتصفح على `http://localhost:8000` للتنقل بين الصفحات.

## المجلدات
- `app/Models`: نماذج بسيطة للتعامل مع المستخدمين والامتحانات والأسئلة عبر PDO.
- `app/Controllers`: وحدات تحكم خفيفة لعرض الصفحات.
- `app/Views`: قوالب الواجهة الأمامية مع التصميم العربي والشعار وروابط تيليغرام وإنستغرام.
- `database/`: ملف مخطط قاعدة البيانات.
- `public/`: نقطة الدخول وملفات الأصول.
- `storage/` و`imports/`: أماكن لحفظ الصور أو ملفات CSV المستوردة.
