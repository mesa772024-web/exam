# دعوة افتتاح مقر مجلس الأعمال العراقي–الأمريكي (A5 عرضي)

- `IUSBC_Invitation.pdf` — النسخة النهائية (210×148 مم، الخطوط مضمّنة، الموقع وQR قابلان للنقر).
- `IUSBC_Invitation.png` — معاينة/مشاركة رقمية.
- `IUSBC_Invitation.idml` — ملف InDesign (DOM 20 = InDesign 2025)، الشعار مضمّن، كل الأشكال والنصوص قابلة للتعديل، Bleed 3 مم.
- `Fonts/` — Amiri وCairo (SIL OFL 1.1) — ثبّتها قبل فتح IDML.
- `src/` — سكربت التوليد (`python3 build.py` ثم `node render.js`).

ملاحظات IDML: النص عربي RTL؛ إن ظهرت الحروف غير متصلة اضبط Paragraph Composer على
Adobe World-Ready Paragraph Composer. الألوان RGB (Navy 0B2A55 / Gold CDA449) — حوّلها إلى CMYK عند الطباعة.
