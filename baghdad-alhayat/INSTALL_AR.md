# تثبيت موقع مكتب بغداد الحياة العلمي — النسخة الثانية

## متطلبات الاستضافة

- PHP 8.1 أو أحدث.
- MySQL 5.7+ أو MariaDB 10.4+ مع قاعدة بيانات ومستخدم جاهزين.
- إضافات PHP: `PDO`, `pdo_mysql`, `mbstring`, `fileinfo`, `json`.
- إضافة `zip` مطلوبة للنسخ الاحتياطي وتحديث ZIP.
- Apache مع `.htaccess` موصى به، أو Nginx مع منع الوصول إلى `storage` و`includes`.
- HTTPS إلزامي في الموقع الحقيقي.

## التثبيت السريع

1. فك ضغط المشروع وارفع محتوياته إلى `public_html` أو مجلد الموقع.
2. امنح خادم PHP صلاحية الكتابة على `storage` و`uploads` فقط.
3. أنشئ قاعدة بيانات MySQL ومستخدماً لها من لوحة الاستضافة.
4. افتح `https://domain.com/install/`.
5. أدخل خادم قاعدة البيانات والمنفذ واسم القاعدة واسم مستخدمها وكلمة مرورها.
6. أدخل اسم المدير واسم الدخول. كلمة مرور الإدارة تقبل 8 أرقام أو أي كلمة مرور من 8 خانات فأكثر.
7. بعد النجاح يُنشأ `storage/installed.lock` ويُقفل المثبّت تلقائياً.
8. ادخل من `https://domain.com/hyt-so-admin-a9/`.

لا توجد بيانات دخول افتراضية. استخدم اسماً غير متوقع، ويفضل كلمة مرور أطول من الحد الأدنى في الموقع الحقيقي.

## التشغيل المحلي

شغّل MySQL من XAMPP أو Laragon، وأنشئ قاعدة بيانات ومستخدماً، ثم شغّل `start-local.cmd` وافتح:

`http://127.0.0.1:8000/install/`

## النسخ والاستعادة

- نسخة الملفات ZIP تستثني `storage` والمواد المرجعية.
- نسخة قاعدة البيانات ملف SQL يحمل توقيع النظام ولا يتضمن كلمة مرور الاتصال.
- الاستعادة تقبل ملف SQL صادر من هذه النسخة فقط، وترفض الأوامر والجداول غير المعروفة، وتنشئ نسخة تلقائية قبل الاستعادة.
- الاستعادة إجراء حساس ويتطلب كلمة مرور المدير الأعلى وكتابة `RESTORE`.

## تحديث ZIP

راجع `UPDATE_PACKAGE_AR.md`. لا ترفع إلا حزمة من مطور موثوق، واحتفظ بنسخة خارج الاستضافة.

## بعد النشر

- فعّل HTTPS وHSTS.
- اجعل صلاحيات `storage/config.php` بأقل مستوى يسمح لـPHP بالقراءة.
- احتفظ بالنسخ الخارجية مشفرة ولا تترك ملفات SQL خارج `storage`.
- راجع سجل التدقيق والأحداث الأمنية دورياً.
- فعّل WAF وحماية DDoS لدى شركة الاستضافة أو Cloudflare؛ تحديد المعدل داخل PHP طبقة إضافية وليس بديلاً عن حماية الشبكة.
